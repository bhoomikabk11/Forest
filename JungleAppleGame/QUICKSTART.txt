🚀 HOW TO RUN (3 STEPS):
--------------------------------------------------------------------------------

1. Install Python Dependencies:
   
   pip install pygame numpy pillow

2. Navigate to game directory:
   
   cd JungleAppleGame

3. Run the game:
   
   python game.py

🧠 HOW CNN WORKS IN THIS GAME:
--------------------------------------------------------------------------------

1. Boy collects falling apple
2. Apple image captured as pygame Surface
3. Image sent to CNN classifier (cnn_predict.py)
4. CNN analyzes color features:
   - Red channel dominance
   - Brightness levels
   - Color balance
5. Classification: GOOD vs DAMAGED
6. Result displayed with confidence score
7. Score updated (only GOOD apples count!)

DAMAGED apples (dark brown) → No points ❌

Try to get the highest score possible!

--------------------------------------------------------------------------------
🔧 TROUBLESHOOTING:
--------------------------------------------------------------------------------

Q: Missing assets error?
A: Run: python create_assets.py

Q: Missing model error?
A: Run: python create_model.py

Q: Import errors?
A: Install: pip install pygame numpy pillow

Q: Game too hard/easy?
A: Edit game.py constants (PLAYER_SPEED, APPLE_FALL_SPEED)
